# مساعد معاملات ليبيا

منصة مستقلة تساعد المستخدم في ليبيا على فهم المعاملات والإجراءات الرسمية، معرفة
المستندات والخطوات والمصادر، ثم اختيار إن كان يريد تنفيذ المعاملة بنفسه أو طلب
مساعدة من مقدم خدمة مستقل.

## حالة المشروع

هذا هو الهيكل الأساسي (skeleton) للمشروع فقط. لا توجد حتى الآن قاعدة بيانات،
مصادقة، بيانات وهمية، أو ميزات مكتملة. الهدف من هذه المرحلة هو تجهيز أساس نظيف
قابل للبناء عليه.

## التقنيات المستخدمة

- [Next.js](https://nextjs.org) (App Router)
- TypeScript
- Tailwind CSS
- npm
- [Supabase](https://supabase.com) (PostgreSQL + Auth + Row Level Security) — سيتم ربطه في مرحلة لاحقة
- Git

المشروع Arabic-first: الاتجاه الافتراضي للواجهة هو RTL (`lang="ar" dir="rtl"`).

## البنية المعمارية المستهدفة (لمراحل لاحقة)

النظام مصمم منذ البداية ليدعم لاحقًا:

1. المعاملات والإجراءات
2. المصادر الرسمية
3. المستخدمين
4. حفظ المعاملات
5. Checklist لكل معاملة
6. مقدمو خدمات مستقلون
7. طلب مساعدة من مقدم خدمة
8. متابعة المعاملة
9. الإشعارات
10. التقييمات
11. لوحة الإدارة
12. AI / RAG (مرحلة لاحقة)

لا شيء من هذه الميزات مبني حاليًا — هذا القسم توثيقي فقط لتوجيه القرارات
المعمارية المستقبلية.

## التشغيل محليًا

```bash
npm install
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000) في المتصفح.

## متغيرات البيئة

انظر ملف [`.env.example`](.env.example). لا يحتوي هذا الملف على أي مفاتيح
حقيقية — هو فقط قائمة بالمتغيرات المتوقعة لاحقًا عند ربط Supabase.

## الأوامر المتاحة

| الأمر | الوصف |
|---|---|
| `npm run dev` | تشغيل بيئة التطوير |
| `npm run build` | بناء نسخة الإنتاج |
| `npm run start` | تشغيل نسخة الإنتاج المبنية |
| `npm run lint` | فحص الكود بـ ESLint |
